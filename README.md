## 📌 About the Project

This portfolio is designed to highlight my projects, technical skills, and professional journey. It emphasizes clean UI, smooth animations, and a scalable, well-structured architecture.

---

## ✨ Features

* ⚡ Fast performance powered by Vite
* 🎨 Modern, clean, and minimal UI
* 🧩 Reusable component-based architecture
* 🎞️ Smooth animations and transitions
* 📱 Fully responsive across all devices
* 🗂️ Well-organized and scalable codebase
* 📬 Contact section for direct communication

---

## 🛠️ Tech Stack

* **Frontend:** React, Aceternity UI, Magic UI
* **Build Tool:** Vite
* **Styling:** Tailwind CSS
* **Animations:** Motion / Framer Motion
* **Code Quality:** ESLint
* **Version Control:** Git
